# 📖 Project Overview

React Product Management System is a modern CRUD application developed using **React**, **Vite**, **Bootstrap 5**, and **React Router DOM**.

The application enables users to create, manage, update, search, and delete products while storing data in the browser using **Local Storage**.

It demonstrates reusable React components, routing, state management, CRUD operations, responsive UI design, and client-side data persistence.
